# 有一说一.SKILL

## 一句话简介

一个基于言论分析的思维体系挖掘工具——帮你把“隐约觉得不对劲”变成可验证的结构化判断。

## 适用场景

本 Skill 专为以下三类场景设计：

1. **阅读他人言论时感到“隐约有问题，但说不上来”**  
   不再停留在直觉层面，而是通过结构化分析定位逻辑漏洞、回避议题或内在矛盾。

2. **想通过一个人的过往言论，推断其深层思维模式**  
   从碎片化观点中提取核心信念、论证习惯与思维边界，生成可解释的认知画像。

3. **想对自己的思考方式进行深度剖析**  
   用同一套框架审视自己的言论或写作，发现盲区、矛盾与隐含假设，辅助批判性思维训练。

## 它能做什么

- 将任意公开言论拆解为结构化的“观点单元”（议题、主张、理由、限定条件、语境）
- 自动/半自动构建言论之间的 “信念网络图”，可视化议题间的逻辑依赖
- 完成四维深度分析：
  - 议题覆盖与回避（思考了什么？回避了什么？）
  - 结论特征与一致性（确定吗？矛盾吗？）
  - 普适性判断（特定案例还是普遍规律？）
  - 主体可互换性测试（换个主体，结论还站得住吗？）
- 挖掘未明说的前提、底层预设与深层张力
- 输出一份包含证据回溯与置信度声明的完整分析报告

## 快速开始

1. **准备语料**  
   收集被分析对象在足够长时间跨度内的公开言论（采访、文章、社交媒体、演讲等）。

2. **补充语境（推荐）**  
   为每条言论标注时间、场合、受众。如无法提供，分析报告需声明局限性。

3. **明确分析范围**  
   是分析所有主题上的言论，还是限定在特定议题范围内？

4. **调用本 Skill**  

## 核心原则

- **证据锚定**：每一项结论都必须能回溯到具体的言论文本。
- **可证伪性**：如果提供相反的言论证据，分析结论可以被修正。
- **避免连贯性强加**：不为了系统性而忽略矛盾；矛盾本身就是重要发现。
- **语境保留**：不得剥离限定条件或脱离原始语境引用主张。
- **不推测动机**：只描述“回避了什么”，不猜测“为什么回避”。

## 适用范围

| 对象类型                     | 适用程度                               |
| ---------------------------- | -------------------------------------- |
| 公共知识分子、政要、学者等   | ✅ 完全适用（可执行全部五步）          |
| 言论较少的个体（<10条核心言论）| ⚠️ 部分适用（仅前两步，不推荐深层分析）|
| 仅有二手转述或虚构人物       | ❌ 不适用（需不同分析框架）            |


> “有一说一”——让分析有据，让判断可验。
